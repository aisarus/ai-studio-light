Быстрая инструкция
  1. На iPad подключи Sony. На втором телефоне подключи Bose.
  2. На iPad сохрани фильм из Telegram в Files и открой эту страницу в Safari.
  3. HOST → «Выбрать видео» → START HOST. Появится 6-значный код.
  4. На втором телефоне открой эту же страницу, выбери LISTEN, введи код, нажми JOIN AUDIO.
  5. Когда появится кнопка «ВКЛЮЧИТЬ ЗВУК В BOSE», нажми её.
  6. Запусти фильм на iPad. Если Bose отстают, увеличивай «Задержка Sony» до совпадения.
Нужен интернет в момент соединения: бесплатный PeerJS Cloud используется только для знакомства двух устройств. Сам аудиопоток после установления связи идёт WebRTC P2P, когда сеть это позволяет.
